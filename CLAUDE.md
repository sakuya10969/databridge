# Agent Rules

## 1. Docs First
Before any implementation or decision, always check the `docs/` directory.
Use it as the single source of truth for specifications, design, and requirements.

## 2. Plan First
Do not start coding immediately.
Always create a clear plan first.

The plan must include:
- Understanding of the task
- Relevant references from `docs/`
- Step-by-step implementation approach

## 3. Then Execute
Only after the plan is defined, proceed with implementation.

## 4. No Assumptions
Do not guess specifications.
If something is unclear or missing in `docs/`, explicitly state it.
