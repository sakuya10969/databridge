# プロダクト定義: 業務データ取り込み基盤

## プロダクト概要

ToB向けSaaSとして提供する「業務データ取り込み基盤」である。
企業が日常的に扱うExcel/CSVファイルを取り込み、検証・変換してデータベースへ安全に投入する。
「ぐちゃぐちゃなExcel/CSVの正規化」が本プロダクトの存在意義である。

## 解決する課題

- Excel/CSVの形式がバラバラで、手作業での整形・検証に膨大な工数がかかる
- 取り込み時のエラーが不透明で、どの行・列に問題があるか特定できない
- 取り込み処理の再現性がなく、同じ形式のファイルでも毎回手動設定が必要
- 誰がいつ何を取り込んだかの記録が残らず、監査対応ができない
- 本番テーブルへの直接書き込みによるデータ破損リスクがある

## ユーザー

- 業務部門の担当者（非エンジニア）: ファイルアップロード・プレビュー・エラー確認を行う
- 情報システム部門: テンプレート作成・列マッピング定義・取り込み設定を管理する
- 管理者: 監査ログの確認・ジョブ履歴の監視を行う

## ユースケース

1. ファイルアップロード: CSV/xlsxファイルをドラッグ&ドロップまたはファイル選択でアップロードする
2. Excelシート選択: 複数シートを持つExcelファイルの場合、対象シートを選択する
3. ヘッダ位置調整: ヘッダ行が1行目でない場合、ヘッダ開始行を指定する
4. プレビュー確認: 取り込み前にデータの先頭N行をテーブル形式で確認する
5. 列マッピング: アップロードファイルの列とDBテーブルの列を対応付ける
6. バリデーション: 型チェック・必須チェック・重複チェック・形式チェックを実行する
7. エラー表示: バリデーションエラーを行・列単位で一覧表示する
8. 取り込み実行: バリデーション通過後、stagingテーブル経由でDBへ投入する
9. ジョブ履歴確認: 過去の取り込みジョブをステータス・日時で一覧確認する
10. テンプレート再利用: 過去の列マッピング・バリデーション設定をテンプレートとして保存・再利用する
11. 再実行: 失敗したジョブを同一設定で再実行する
12. 監査ログ: 誰がいつどのファイルを取り込んだかを記録・閲覧する

## MVP機能

以下をMVPスコープとする。

| 機能 | 説明 |
|------|------|
| CSV/xlsxアップロード | ドラッグ&ドロップ対応。1ファイル=1ジョブ |
| プレビュー | 先頭50行をテーブル表示。シート選択・ヘッダ行指定を含む |
| 列マッピング | ソース列とターゲット列のGUI対応付け |
| バリデーション | panderaによる型・必須・重複・形式チェック |
| エラー表示 | 行・列単位のエラー一覧。エラー内容・該当値を表示 |
| ジョブ管理 | ジョブ一覧・詳細・ステータス表示 |
| ステータス管理 | uploaded → parsing → validating → importing → completed / failed |
| テンプレート保存 | 列マッピング+バリデーション設定の保存・読み込み |
| 監査ログ（簡易） | ジョブ単位の操作ログ記録・閲覧 |
| 再実行 | 失敗ジョブの同一設定での再実行 |

## 拡張候補（MVP後）

- xlsb形式対応（pyxlsb利用、依存は導入済み）
- パスワード付きExcel対応（msoffcrypto-tool利用、依存は導入済み）
- 大容量ファイル対応（チャンク処理・ストリーミング）
- 非同期処理強化（バックグラウンドワーカー）
- 権限管理（ロールベースアクセス制御）
- 複数テーブル同時取り込み

## 非機能要件

- レスポンス: プレビュー表示は3秒以内とする
- ファイルサイズ: MVPでは50MB・10万行までを対象とする
- データ安全性: 本番テーブルへの直接書き込みは禁止。staging経由を必須とする
- 冪等性: 同一ジョブの再実行で重複データが発生しないこととする
- 可観測性: 全ジョブの実行ログ・エラーログを保持する
- 監査性: 操作者・操作日時・対象ファイル・結果を記録する

## 成功条件

- ファイルアップロードから取り込み完了まで、画面遷移のみで完結すること
- バリデーションエラーが行・列単位で特定でき、修正指示が出せること
- 同一形式のファイルをテンプレートで繰り返し取り込めること
- 失敗ジョブを設定変更なしで再実行できること

## スコープ外

- ファイルの自動取得（メール・SFTP・API連携等）
- リアルタイムデータ同期
- データの加工・変換ロジックのカスタマイズUI
- マルチテナント対応（MVP時点）
- ユーザー認証・認可（MVP時点）
- 通知機能（メール・Slack等）
