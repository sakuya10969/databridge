# 要件定義書: 帳票テンプレート管理

## はじめに

本ドキュメントはReportサブシステムの帳票テンプレート管理機能のMVP要件を定義する。
帳票テンプレートのCRUD（作成・一覧・詳細・更新・削除）およびフィールド定義管理を責務とする。
帳票出力ジョブの作成・生成・ダウンロードは別spec（report-generation）で管理する。

## 用語集

- **Report_Template**: 帳票出力のレイアウト・フィールド定義。Import用テンプレートとは完全に別概念
- **Report_Template_Field**: 帳票テンプレートに紐づく出力フィールド定義。フィールドキー・ラベル・データソースパス・表示順・書式タイプ・書式パターン・必須フラグ・デフォルト値・列幅・集計関数を持つ
- **ReportType**: 帳票種別enum。list（一覧票）・single（単票）・summary（集計票）
- **Layout_Definition**: 帳票レイアウト定義。タイトル・ページサイズ・向き・ヘッダ・フッタ・グルーピング・集計設定をJSONBで格納する

## 要件

### 要件 1: 帳票テンプレートCRUD

**ユーザーストーリー:** 情報システム部門の担当者として、帳票テンプレートを作成・管理したい。それにより、帳票出力のフォーマットを標準化・再利用できる。

#### 受入条件

1. WHEN 帳票テンプレート作成が要求された場合、THE System SHALL テンプレート名・説明・帳票種別（list/single/summary）・デフォルト出力形式・対象リソース種別・Layout_Definition・フィールド定義を保存する
2. WHEN 帳票テンプレート一覧が要求された場合、THE System SHALL 全有効テンプレートを名前・帳票種別・出力形式・作成日時と共にページネーション付きで返す
3. WHEN 帳票テンプレート詳細が要求された場合、THE System SHALL テンプレートの全情報（Report_Template_Field含む）を返す
4. WHEN 帳票テンプレート更新が要求された場合、THE System SHALL 指定されたフィールドを更新し、updated_atを更新する
5. WHEN 帳票テンプレート削除が要求され、関連するReport_Jobが存在しない場合、THE System SHALL テンプレートを物理削除する
6. WHEN 帳票テンプレート削除が要求され、関連するReport_Jobが存在する場合、THE System SHALL テンプレートのis_activeをfalseに設定する（論理削除）
7. WHEN 同一名の帳票テンプレートが既に存在する場合、THE System SHALL 作成を拒否し、名前重複エラーを返す
8. WHEN 帳票テンプレートの作成・更新・削除が成功した場合、THE Audit_Log SHALL 操作種別・対象テンプレートID・タイムスタンプを記録する

### 要件 2: 帳票フィールド定義

**ユーザーストーリー:** 情報システム部門の担当者として、帳票テンプレートに出力フィールドを定義したい。それにより、帳票の出力内容と書式を制御できる。

#### 受入条件

1. WHEN 帳票テンプレート作成時にフィールド定義が指定された場合、THE System SHALL 各フィールド（フィールドキー・ラベル・データソースパス・表示順・書式タイプ・書式パターン・必須フラグ・デフォルト値・列幅・集計関数）をReport_Template_Fieldとして保存する
2. WHEN 同一テンプレート内でフィールドキーが重複した場合、THE System SHALL 保存を拒否し、フィールドキー重複エラーを返す
3. WHEN 書式タイプが指定された場合、THE System SHALL string/integer/decimal/date/datetime/currency/percentageのいずれかであることを検証する
