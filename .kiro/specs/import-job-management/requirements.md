# 要件定義書: Importジョブ一覧・詳細・ステータス管理

## はじめに

本ドキュメントはImportサブシステムのジョブ管理画面機能のMVP要件を定義する。
Importジョブの一覧表示・詳細表示・ステータスフィルタ・ダッシュボード画面を責務とする。
ジョブの作成・パース・バリデーション・取り込みの実行ロジックは他specで定義済みの前提とする。

## 用語集

- **Import_Job**: 1ファイルの取り込み処理の実行単位。ステータス遷移（uploaded→parsing→validating→importing→completed/failed）を持つ
- **JobStatus**: Import_Jobのステータスenum

## 要件

### 要件 1: ジョブ一覧表示

**ユーザーストーリー:** 管理者として、全取り込みジョブの状況を一覧で確認したい。それにより、取り込み処理の進捗と履歴を把握できる。

#### 受入条件

1. WHEN ジョブ一覧が要求された場合、THE System SHALL 全Import_Jobをステータス・作成日時・ファイル名と共にページネーション付きで返す
2. WHEN ステータスフィルタが指定された場合、THE System SHALL 指定ステータスのジョブのみを返す

### 要件 2: ジョブ詳細表示

**ユーザーストーリー:** 管理者として、特定のジョブの詳細情報を確認したい。それにより、ジョブの処理状況と設定内容を把握できる。

#### 受入条件

1. WHEN ジョブ詳細が要求された場合、THE System SHALL ステータス・エラー件数・ファイル情報・列マッピング・タイムスタンプを含む詳細情報を返す
2. IF 存在しないジョブIDが指定された場合、THEN THE System SHALL 404エラーを返す

### 要件 3: ダッシュボード画面

**ユーザーストーリー:** 業務部門の担当者として、ダッシュボードからジョブの状況を一目で確認したい。それにより、日常業務の取り込み状況を効率的に把握できる。

#### 受入条件

1. WHEN ダッシュボード画面が表示された場合、THE System SHALL ジョブ一覧テーブル（ステータスフィルタ・ページネーション付き）を表示する
2. WHEN ジョブのステータスが変化した場合、THE System SHALL ポーリングにより自動的に画面を更新する
3. WHEN ジョブ行がクリックされた場合、THE System SHALL ジョブ詳細画面へ遷移する
