# 機能要件

本システムは「データ取り込み（Import）」と「帳票出力（Report）」の2つの責務を持つ。
それぞれ独立した機能群として整理する。

---

## A. データ取り込み機能（Import）

### MVP機能一覧

### 1. ファイルアップロード

| 項目 | 内容 |
|------|------|
| 対応形式 | CSV, xlsx |
| アップロード方式 | ドラッグ&ドロップ / ファイル選択 |
| 制約 | 1ファイル = 1ジョブ。50MB・10万行まで |
| 処理 | ディスク保存 → ジョブ作成（status: uploaded） |

### 2. プレビュー

| 項目 | 内容 |
|------|------|
| 表示行数 | 先頭50行 |
| 表示形式 | TanStack Table + shadcn/ui Table |
| 付随機能 | Excelシート選択、ヘッダ開始行指定 |
| 仮想スクロール | TanStack Virtual（列数が多い場合に対応） |

### 3. 列マッピング

| 項目 | 内容 |
|------|------|
| 操作 | ソース列（ファイル）とターゲット列（DB）のGUI対応付け |
| UI | マッピングテーブル（ドロップダウン選択） |
| テンプレート連携 | 既存テンプレートからマッピングを読み込み可能 |

### 4. バリデーション

| 項目 | 内容 |
|------|------|
| エンジン | pandera DataFrameSchema（動的構築） |
| チェック項目 | 型（int/float/str/datetime/bool）、必須、重複、形式（regex）、範囲 |
| 実行タイミング | 列マッピング設定後に明示的に実行 |
| 結果 | エラー一覧をDBに保存 → フロントで表示 |

### 5. エラー表示

| 項目 | 内容 |
|------|------|
| 粒度 | 行番号・列名単位 |
| 表示内容 | エラー種別、該当値、エラーメッセージ |
| UI | エラーテーブル（TanStack Table、ソート・フィルタ対応） |

### 6. ジョブ管理

| 項目 | 内容 |
|------|------|
| 一覧 | 全ジョブをステータス・日時・ファイル名で一覧表示 |
| 詳細 | ステータス遷移・エラー件数・ファイル情報・タイムスタンプ |
| ポーリング | TanStack Query refetchIntervalでステータス自動更新 |

### 7. ステータス管理

| ステータス | 意味 |
|-----------|------|
| uploaded | ファイルアップロード完了 |
| parsing | パース処理中 |
| validating | バリデーション実行中 |
| importing | DB取り込み中 |
| completed | 取り込み完了 |
| failed | 処理失敗（再実行可能） |

### 8. テンプレート保存

| 項目 | 内容 |
|------|------|
| 保存内容 | 列マッピング定義 + バリデーション設定（JSON） |
| 操作 | 名前を付けて保存 / 一覧から選択して読み込み |
| 用途 | 同一形式ファイルの繰り返し取り込み |

### 9. 監査ログ（簡易）

| 項目 | 内容 |
|------|------|
| 記録内容 | 操作者、操作種別、対象ジョブ/ファイル、タイムスタンプ、結果 |
| 閲覧 | 一覧テーブル（フィルタ・ソート対応） |
| 対象操作 | アップロード、バリデーション実行、取り込み実行、再実行 |

### 10. 再実行

| 項目 | 内容 |
|------|------|
| 対象 | status: failed のジョブ |
| 動作 | 同一設定（列マッピング・バリデーション）で再実行 |
| 冪等性 | stagingテーブルをクリアしてから再投入 |

## B. 帳票出力機能（Report）

importとreportは別責務である。importは「外部ファイル → 内部DB」、reportは「内部DB → 外部ファイル」の方向性を持つ。
帳票テンプレートはimport用テンプレート（templates テーブル）とは完全に別概念として管理する。

### MVP機能一覧

### 11. 帳票テンプレート管理

| 項目 | 内容 |
|------|------|
| 作成 | 帳票名・説明・出力形式・レイアウト定義・対象リソース種別を指定して作成 |
| 一覧 | 全帳票テンプレートを名前・出力形式・作成日時で一覧表示 |
| 詳細 | テンプレート定義の全情報（フィールド定義含む）を表示 |
| 更新 | テンプレート定義の編集（名前・説明・レイアウト・フィールド） |
| 削除 | 未使用テンプレートの削除（出力ジョブが存在する場合は論理削除） |

### 12. 帳票フィールド定義

| 項目 | 内容 |
|------|------|
| 定義単位 | 帳票テンプレートに紐づくフィールド群 |
| 設定項目 | フィールドキー、ラベル、データソースパス、表示順、書式、必須、デフォルト値 |
| 帳票種別 | 一覧票（list）: 複数行データの表形式出力 |
|  | 単票（single）: 1レコードの詳細出力 |
|  | 集計票（summary）: グループ化・集計を含む出力 |
| 書式タイプ | string / integer / decimal / date / datetime / currency / percentage |

### 13. 帳票出力ジョブ作成

| 項目 | 内容 |
|------|------|
| 操作 | 帳票テンプレート選択 → 出力条件指定 → ジョブ作成 |
| 出力形式 | PDF / Excel（xlsx）/ CSV |
| フィルタ条件 | JSONB形式で柔軟に指定（日付範囲・ステータス・操作者等） |
| ソート条件 | JSONB形式で指定（カラム名・昇順/降順） |
| 処理 | 非同期ジョブとして実行（status: pending → generating → completed / failed） |

### 14. 帳票出力ステータス管理

| ステータス | 意味 |
|-----------|------|
| pending | 出力リクエスト受付済み |
| generating | 帳票生成処理中 |
| completed | 生成完了・ダウンロード可能 |
| failed | 生成失敗（再実行可能） |

### 15. 帳票ファイルダウンロード

| 項目 | 内容 |
|------|------|
| 対象 | status: completed の出力ジョブに紐づくファイル |
| 方式 | report_outputs テーブルのファイルパスからストリーミングダウンロード |
| メタデータ | ファイル名・MIMEタイプ・ファイルサイズ・チェックサム |
| 再ダウンロード | 生成済みファイルはサーバー上に保持し、何度でもダウンロード可能 |

### 16. 帳票出力ジョブ管理

| 項目 | 内容 |
|------|------|
| 一覧 | 全出力ジョブをステータス・日時・テンプレート名で一覧表示 |
| 詳細 | ステータス・出力条件・出力行数・生成ファイル情報・タイムスタンプ |
| ポーリング | TanStack Query refetchIntervalでステータス自動更新 |

### 17. 帳票出力再実行

| 項目 | 内容 |
|------|------|
| 対象 | status: failed の出力ジョブ |
| 動作 | 同一テンプレート・同一条件で再実行 |
| 既存ファイル | 再実行時は新しいreport_outputsレコードを作成（旧ファイルは保持） |

### 18. 帳票出力の監査ログ

| 項目 | 内容 |
|------|------|
| 記録内容 | 操作者、操作種別、対象ジョブ/テンプレート、タイムスタンプ、結果 |
| 対象操作 | テンプレート作成・更新・削除、出力ジョブ作成、ダウンロード、再実行 |
| 統合 | 既存のaudit_logsテーブルにreport系イベントを追加（resource_type拡張） |

### 帳票出力のフィルタ条件（filter_conditions）仕様

JSONB形式で格納する。以下の構造を標準とする。

```json
{
  "filters": [
    { "field": "status", "operator": "eq", "value": "completed" },
    { "field": "created_at", "operator": "gte", "value": "2025-01-01T00:00:00Z" },
    { "field": "created_at", "operator": "lte", "value": "2025-12-31T23:59:59Z" },
    { "field": "operator", "operator": "eq", "value": "田中太郎" }
  ],
  "sort": [
    { "field": "created_at", "direction": "desc" }
  ]
}
```

対応演算子: `eq`, `neq`, `gt`, `gte`, `lt`, `lte`, `in`, `like`

### 帳票レイアウト定義（layout_definition）仕様

JSONB形式で格納する。帳票種別に応じた構造を持つ。

```json
{
  "type": "list",
  "title": "取り込みジョブ一覧",
  "page_size": "A4",
  "orientation": "landscape",
  "header": { "show": true, "text": "業務データ取り込み基盤 — ジョブ一覧レポート" },
  "footer": { "show": true, "text": "ページ {page} / {total_pages}" },
  "grouping": null,
  "aggregation": null
}
```

集計票の場合:
```json
{
  "type": "summary",
  "title": "月次取り込み集計",
  "grouping": { "field": "operator", "label": "操作者別" },
  "aggregation": [
    { "field": "total_rows", "function": "sum", "label": "合計行数" },
    { "field": "id", "function": "count", "label": "ジョブ数" }
  ]
}
```
