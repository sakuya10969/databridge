# プロジェクト概要

## プロダクト名

業務データ取り込み基盤（Data Import Platform）

## 概要

ToB向けSaaSとして提供する、Excel/CSVファイルの取り込み・検証・変換・DB投入基盤である。
企業が日常的に扱う「ぐちゃぐちゃなExcel/CSV」を正規化し、安全にデータベースへ投入することが目的である。

## 解決する課題

| 課題 | 本プロダクトによる解決 |
|------|----------------------|
| Excel/CSVの形式がバラバラで手作業整形に工数がかかる | テンプレート化された列マッピング・バリデーションで自動処理 |
| エラーが不透明で問題箇所を特定できない | 行・列単位のエラー可視化 |
| 同じ形式でも毎回手動設定が必要 | テンプレート保存・再利用による再現性確保 |
| 取り込み履歴が残らず監査対応不可 | 監査ログによる全操作記録 |
| 本番テーブル直書きによるデータ破損リスク | staging経由の安全な投入フロー |

## ユーザー

| ロール | 主な操作 |
|--------|---------|
| 業務部門担当者（非エンジニア） | ファイルアップロード・プレビュー確認・エラー確認 |
| 情報システム部門 | テンプレート作成・列マッピング定義・取り込み設定管理 |
| 管理者 | 監査ログ確認・ジョブ履歴監視 |

## 取り込みフロー

```
ファイルアップロード
  → シート選択（Excel）
  → ヘッダ行指定
  → プレビュー確認
  → 列マッピング
  → バリデーション実行
  → エラー確認・修正
  → 取り込み実行（staging → 本番）
  → 完了 / 失敗 → 再実行
```

## ステータス遷移

```
uploaded → parsing → validating → importing → completed
                                            → failed（再実行可能）
```

## 非機能要件

- プレビュー表示: 3秒以内
- 対応ファイルサイズ: MVP時点で50MB・10万行まで
- データ安全性: 本番テーブル直書き禁止、staging経由必須
- 冪等性: 再実行で重複データが発生しない
- 監査性: 操作者・日時・対象ファイル・結果を全て記録

## スコープ外（MVP時点）

- ファイル自動取得（メール・SFTP・API連携）
- リアルタイムデータ同期
- データ加工・変換カスタマイズUI
- マルチテナント
- ユーザー認証・認可
- 通知機能
