# プロジェクト概要

## プロダクト名

業務データ取り込み・帳票出力基盤（Data Import & Report Platform）

## 概要

ToB向けSaaSとして提供する、Excel/CSVファイルの取り込み・検証・変換・DB投入、および蓄積データの帳票出力基盤である。

- **Import（取り込み）**: 企業が日常的に扱う「ぐちゃぐちゃなExcel/CSV」を正規化し、安全にデータベースへ投入する
- **Report（帳票出力）**: 取り込み済みデータを所定のフォーマット（PDF / Excel / CSV）で帳票として出力する

importとreportは別責務として扱う。importは「外部ファイル → 内部DB」、reportは「内部DB → 外部ファイル」の方向性を持つ。

## 解決する課題

| 課題 | 本プロダクトによる解決 |
|------|----------------------|
| Excel/CSVの形式がバラバラで手作業整形に工数がかかる | テンプレート化された列マッピング・バリデーションで自動処理 |
| エラーが不透明で問題箇所を特定できない | 行・列単位のエラー可視化 |
| 同じ形式でも毎回手動設定が必要 | テンプレート保存・再利用による再現性確保 |
| 取り込み履歴が残らず監査対応不可 | 監査ログによる全操作記録 |
| 本番テーブル直書きによるデータ破損リスク | staging経由の安全な投入フロー |
| 蓄積データの帳票作成に手作業が必要 | 帳票テンプレート定義による自動出力 |
| 帳票出力の履歴・監査証跡がない | 帳票出力ジョブ管理・監査ログによる追跡 |
| 帳票フォーマットが属人化している | テンプレート化による標準化・再利用 |

## ユーザー

| ロール | 主な操作 |
|--------|---------|
| 業務部門担当者（非エンジニア） | ファイルアップロード・プレビュー確認・エラー確認・帳票出力リクエスト・帳票ダウンロード |
| 情報システム部門 | 取り込みテンプレート作成・列マッピング定義・帳票テンプレート作成・出力条件設定 |
| 管理者 | 監査ログ確認・ジョブ履歴監視（取り込み・帳票出力の両方） |

## 取り込みフロー

```
ファイルアップロード
  → シート選択（Excel）
  → ヘッダ行指定
  → プレビュー確認
  → 列マッピング
  → バリデーション実行
  → エラー確認・修正
  → 取り込み実行（staging → 本番）
  → 完了 / 失敗 → 再実行
```

## 帳票出力フロー

```
帳票テンプレート選択（または新規作成）
  → 出力条件指定（フィルタ・ソート・出力形式）
  → 帳票出力ジョブ作成
  → データ抽出・帳票生成（非同期）
  → 完了 / 失敗
  → ファイルダウンロード / 再実行
```

## ステータス遷移

### 取り込みジョブ（ImportJob）

```
uploaded → parsing → validating → importing → completed
                                            → failed（再実行可能）
```

### 帳票出力ジョブ（ReportJob）

```
pending → generating → completed
                     → failed（再実行可能）
```

## 非機能要件

- プレビュー表示: 3秒以内
- 対応ファイルサイズ: MVP時点で50MB・10万行まで（取り込み）
- データ安全性: 本番テーブル直書き禁止、staging経由必須
- 冪等性: 再実行で重複データが発生しない（取り込み）
- 帳票出力: 同一条件での再生成が可能
- 監査性: 操作者・日時・対象ファイル・結果を全て記録（取り込み・帳票出力の両方）
- 帳票ファイル保持: 生成済みファイルはサーバー上に保持し、再ダウンロード可能とする

## スコープ外（MVP時点）

- ファイル自動取得（メール・SFTP・API連携）
- リアルタイムデータ同期
- データ加工・変換カスタマイズUI
- マルチテナント
- ユーザー認証・認可
- 通知機能
- 帳票のスケジュール自動出力
- 帳票のメール自動送信
- 帳票レイアウトのGUIエディタ
